# Awesome GEO

## Project Overview
Open-source curated list of free platforms and open-source repos for Generative Engine Optimization (GEO) — SEO for the AI era. This repo holds the data, the verification scripts and the generated README.

The companion website (https://geo.deeflect.com, listed as `homepage` in `package.json`) is not in this repo. The local `website/` folder is empty and untracked.

## Architecture
- `data/categories.yaml` + `data/sites/*.yaml` — platform listings, one YAML array per category
- `data/repo-categories.yaml` + `data/repos/*.yaml` — open-source repo listings, one YAML array per category
- `scripts/` — TypeScript scripts run with `tsx`: data validation, README generation, site and repo verification, scoring
- `README.md` — generated by `scripts/generate-readme.ts` from the data. Don't edit it by hand. The static sections (Why GEO, AI Discoverability, crawler table, Research & Reading) live as template text inside that script.
- `docs/` — short guides linked from the README; `docs/plans/` holds March 2026 plans for the website

## Commands
- `npm run validate` — typecheck, `check-data`, regenerate `README.md`. Run before every commit.
- `npm run check-site -- --url <root> --sample-profile <url>` / `verify-all` / `verify-pr` — live site checks: robots.txt access for 7 AI crawlers, indexability, link type, authority. Authority uses Open PageRank (`OPENPAGERANK_API_KEY`) and Tranco.
- `npm run refresh-authority`, `refresh-ai-access`, `score-sites` — refresh stored metrics and GEO scores
- `npm run refresh-repos` — refresh `stars`, `language`, `license`, `pushedAt` for every repo entry from the GitHub API (set `GITHUB_TOKEN`, e.g. `$(gh auth token)`); skips archived, renamed and missing repos
- `npm run verify-repo-pr` — GitHub checks for changed repo entries; writes `verify-repo-report.md` (`verify-pr` writes `verify-report.md`; both gitignored)

## CI (`.github/workflows/`)
- `update-readme.yml` — on push to `main` touching data or the generator: typecheck, check-data, regenerate README, commit it if changed
- `verify-pr.yml` — on PRs touching `data/`: verifies changed sites and repos and comments the reports on the PR
- `weekly-verify.yml` — Mondays 06:00 UTC: `verify-all`, `score-sites`, regenerate README, open a PR on `auto/weekly-verify`

## Key Files
- `data/` — source of truth
- `scripts/generate-readme.ts` — README template and generator
- `scripts/lib.ts` — shared types, YAML read helpers, `writeSitesFile` (sites only; repo YAML is edited by hand), scoring
- `CONTRIBUTING.md` — contribution rules and entry formats
